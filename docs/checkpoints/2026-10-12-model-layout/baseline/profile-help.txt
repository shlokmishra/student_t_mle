Profile Student-t Gibbs and RATTLE cost, ESS/sec, and ESJD locally. The
primary Gibbs timing path is the production `numba_full` backend. The script
also includes a granular NumPy pair-sweep profiler so each conceptual Gibbs
substep can be timed for optimization analysis.
